# Smart Student Expense & Budget Analyzer

## Problem Statement

Students often have limited monthly income or allowances and need to manage their daily expenses. Without proper tracking, it can become difficult to understand where money is being spent, whether the monthly budget is being followed, and how much money is available for financial goals.

The Smart Student Expense & Budget Analyzer is a Python-based command-line application that helps students record and manage their expenses, set budgets, analyze spending patterns, manage financial goals, record income, and generate a financial report.

## Scope

The project focuses on personal financial management for students through a simple command-line interface.

The system provides the following major functions:

- Expense management
- Monthly and category budget management
- Spending analysis
- Financial goal management
- Income management
- Financial report generation

The application stores information locally using JSON files.

## Target Users

The primary users of the system are:

- College students
- Students managing a monthly allowance
- Students who want to track personal expenses
- Students who want to set and monitor financial goals

## Objectives

The main objectives of the project are:

1. To provide a simple way to record daily expenses.
2. To allow users to set and monitor monthly budgets.
3. To analyze spending using basic algorithms.
4. To help users track financial goals.
5. To allow users to record their monthly income.
6. To generate a summary of the user's financial information.
7. To demonstrate Python programming and problem-solving concepts.

## High-Level Features

### 1. Expense Management

Users can:

- Add expenses
- View expenses
- Search expenses
- Filter expenses by category
- Edit expenses
- Delete expenses

### 2. Budget Management

Users can:

- Set a monthly budget
- Set category-wise budgets
- View budget status
- Check budget warnings

### 3. Spending Analytics

The system can calculate:

- Total spending
- Average expense
- Highest expense
- Lowest expense
- Spending by category
- Highest spending category
- Number of transactions

### 4. Financial Goals

Users can:

- Create financial goals
- View goals
- Update saved amounts
- Delete goals
- Track goal progress

### 5. Income Management

Users can:

- Set monthly income
- View monthly income

### 6. Financial Reports

The system generates a summary containing:

- Income
- Total spending
- Remaining money
- Expense statistics
- Category analysis
- Budget status
- Financial goal progress

## Technology Used

- Python
- JSON
- Python unittest
- Command Line Interface (CLI)

## Storage

The application uses local JSON files for storing:

- Expenses
